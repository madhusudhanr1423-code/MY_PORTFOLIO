# Madhu — Portfolio

Personal portfolio site for a freelance full-stack web developer, showcasing project work, services, and a contact flow for potential clients.

🔗 **Live site:** https://my-portfolio-5eqd.vercel.app/

## Tech Stack
- React + TypeScript
- Next.js
- Tailwind CSS
- Vercel (deployment)

## Features
- Project showcase with live demo links
- Services and process breakdown
- Contact form with project type and budget selection
- Fully responsive design

## Featured Projects
- Willow & Stone Studio — full-stack booking platform
- Vesper Estate — real estate showcase site
- Aurevia Health Care — healthcare service site
- Saffron House — restaurant site
- NovaFlow — SaaS marketing site
