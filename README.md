# Pixel Perfect Studio

Build a premium, modern, fully responsive portfolio website for a Full-Stack Web Developer. The design should feel like a high-end digital agency rather than a typical developer portfolio.

Design Style:

- Premium, minimal, elegant

- Apple, Linear, Vercel, Framer inspired

- Dark theme

- Large typography

- Clean grid layout

- Smooth micro-interactions

- Plenty of whitespace

- Glassmorphism used subtly

- Professional, not flashy

- Excellent mobile responsiveness

- WCAG accessible

Tech Stack:

- Next.js

- TypeScript

- Tailwind CSS

- Framer Motion

- shadcn/ui

- Lucide Icons

Color Palette:

Background: #0B0B0B

Borders: rgba(255,255,255,0.08)

Typography:

Headings: General Sans (or Satoshi if available)
